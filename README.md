# 粥粥记账 · Zhouzhou Ledger

一个无需账号和服务器的 Android 本地记账应用，用 Q 版伙伴和“大红”趣味对照陪你记录日常消费。

## 功能

- 记录支出、收入、退款和转账，编辑分类、商户、日期及备注。
- 按月浏览和搜索流水，通过日历、收支走势和分类统计查看消费。
- 设置月预算、自定义分类，导出 CSV。
- 切换毛茸侦察员、麦晓雯和猫耳伙伴三位 Q 版伙伴。
- 将支出显示为“约几只怀表、几根金条”，可关闭或自行调整参考金额，真实人民币金额始终保留。
- 授权后尝试从付款通知或可访问的付款页面生成候选，在“待核对”中检查后入账。

## 使用

需要 Android 8.0 或更新版本。安装 APK 后即可手动记账。

1. 点击底部“记一笔”新增账目，在账本、日历和统计页查看记录。
2. 如需自动识别，进入“我的 → 自动记账”，开启对应选项并选择来源应用。
3. 通知识别需要“通知使用权”，付款页面识别需要系统无障碍权限。
4. 在右上角“待核对”检查金额、商户、日期及重复情况，再确认入账。

后台清理可能中断识别服务；系统权限被关闭后，需要手动重新开启。自动识别仍在适配中，可能漏记、误记或重复，请以支付平台和银行记录核账。

不同品牌的权限与后台入口见 [安卓机型适配指南](docs/android-compatibility.md)。应用内“我的 → 自动记账 → 机型与后台设置”提供设置入口、操作提示和可手动复制的兼容性信息。

## 本地数据

应用无网络权限，不上传账目；数据保存在手机上。数据库和导出的 CSV 未额外加密，CSV 暂不支持导入恢复。卸载、清除数据或设备损坏可能导致账本丢失。详见 [隐私说明](PRIVACY.md)。

## 构建

使用 Java 17、Android 原生控件和 SQLite。需要 JDK 17 或 21、Android SDK 35、Build-tools 35.0.0；设置 `JAVA_HOME` 与 `ANDROID_HOME`，或在 `local.properties` 中配置 SDK 路径。

Windows：

```powershell
.\gradlew.bat assembleDebug
```

macOS / Linux：

```sh
sh ./gradlew assembleDebug
```

APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。PowerShell 也可运行 `./build-apk.ps1`，生成 `ZhouzhouLedger.apk`。首次构建需要下载工具和依赖，应用运行无需服务器。

当前源码版本为 v0.4.1，更名后的 APK 尚未生成。保留相同应用 ID 和签名即可覆盖更新，请勿通过卸载解决更新问题。
