# 一隅记账 0.3 界面约定

## 视觉方向

把账本做成完整的随身财务工具：雾白背景、深蓝数字、柔和靛蓝动作色，首页以月度财务面板和分日流水建立层级，原创线性图标贯穿分类与导航。参考截图用于理解功能和交互，不使用第三方插画、头像、图标或页面像素。

## 内容结构

- 底部固定账本、日历、统计、我的，中间放置快速记账入口。
- 账本显示所选月真实收支、预算及分日流水；待核对收进顶部收件入口。
- 日历按日期展示实际支出并可选择当日流水；统计提供每日走势和分类占比，汇总不受列表上限影响。
- 全屏记账页提供类型切换、分类图标网格、日期时间、商户备注与数字键盘。
- 我的提供预算、分类、数据管理和自动识别入口；权限不足有明确操作，诊断显示服务最后收到事件与解析结果。
- 空账本显示明确下一步，不预置虚构交易或演示数据。

## 交互

底部导航用图标和文字标记选中态；页面与月份切换短淡入，尊重系统关闭动画；分类选中状态与按压波纹即时反馈。日历选日更新流水，图表收支切换更新真实数据。保存失败保留编辑内容以便重试。高风险自动判断先进入待核对，日期待核对不允许直接确认。

## 实现边界

Android 原生控件与自绘矢量图形，无外部字体、远程图片和 UI 运行库。排版使用 sp，操作目标至少 48dp，长金额适应可用宽度。

本轮已在一加 13（Android 17 / API 37）查看实机竖屏界面，仅覆盖实际观察到的画面。尚未完成横屏、旋转状态恢复、大字体或无障碍体验验收，不将竖屏查看视为这些场景已经通过。
