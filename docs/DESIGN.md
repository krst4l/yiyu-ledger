# 一隅记账 0.4 界面约定

## 视觉方向

把账本做成安静、利落的随身财务终端：炭黑背景、灰绿层级、暖白数字，以少量红色突出支出与主要动作。用原创 Q 版角色和物品示意图建立亲近感，财务内容保持清晰。所有图形由项目独立绘制，不使用官方游戏角色、标识、截图或其他作者的二创素材。

统一颜色：背景 `#101412`、表面 `#19201D`、文字 `#F1F2EC`、次级文字 `#9AA89E`、红色 `#E35B53`、分隔线 `#303A34`、红色底 `#35231F`。以对齐、留白、字重和细分隔建立层级，减少卡片；图标底与比例条采用小圆角，数字和图表刻度适当使用系统等宽字。

## 内容结构

- 底部固定账本、日历、统计、我的，中间放置记一笔入口，保留熟悉的财务用语。
- 账本显示所选月真实收支、预算及分日流水；待核对收进顶部收件入口。
- 月度支出与每笔支出旁可显示“≈ 物品数量”，真实人民币始终是主信息。收入、退款、转账不显示支出折算。
- 日历按日期展示实际支出并可选择当日流水；统计提供每日走势和分类占比，汇总不受列表上限影响。每日支出用红色柱、收入用低饱和暖白柱，明确标记图例。
- 全屏记账页提供类型切换、分类图标网格、日期时间、商户备注与数字键盘。
- 我的提供侦察、支援、工程三种原创角色外观，以及“战利品等价”开关和每件参考金额设置；预算、分类、数据管理、自动记账入口继续可用。
- 空账本显示明确下一步，不预置虚构交易、演示柱形或成就。

## 物品等价

内置资料是 [2025-12-12 的 78 项第三方红色收藏品快照](loot-reference.md)，不是当前游戏全量图鉴。57 项有来源明确的历史均价，以“赛伊德的怀表对应 ¥20”为趣味基准按相对数值生成默认人民币参考；21 项无历史均价，保持未设置，在用户设定前不参与。

每件人民币参考金额均可修改，数量按“真实支出 ÷ 单件参考金额”展示近似值，并保留 `≈`。改价只影响展示，不变更 SQLite 记录、收支汇总、预算或 CSV。不将游戏哈夫币与人民币建立实际汇率，不实时抓取交易行。物品图形按怀表、金条、箱体等通用形状绘制，作为示意而非游戏图标复刻。

## 交互

底部导航用图标和文字标记选中态；页面与月份切换短淡入，尊重系统关闭动画；分类选中状态与按压波纹即时反馈。日历选日更新流水，图表收支切换更新真实数据。角色切换仅改变外观，不改变识别能力或金额规则。

保存失败保留编辑内容以便重试。高风险自动判断先进入待核对，日期待核对不允许直接确认。趣味展示可以关闭，不增加记一笔所需步骤。

## 实现与验收边界

Android 原生控件与自绘矢量图形，无外部字体、远程图片和 UI 运行库。排版使用 sp，操作目标至少 48dp，长金额适应可用宽度。绘图保留真实金额比例，零金额显示空状态，不用装饰图形伪造数据。

v0.4.0 调试 APK 已构建并在一加 13 保留数据覆盖安装、启动，未运行测试、lint 或类型检查。本次视觉、交互、角色、物品等价、横屏、大字体及无障碍体验尚未经用户验收；安装和进程启动不代表这些体验已经通过。此前 v0.3.0 在一加 13（Android 17 / API 37）的竖屏观察仅针对当时版本。
