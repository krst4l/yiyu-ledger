# 界面设计

粥粥记账以深色财务界面搭配 Q 版伙伴，真实金额始终是主要信息。

## 视觉

背景 `#101412`、表面 `#19201D`、文字 `#F1F2EC`、次级文字 `#9AA89E`、红色 `#E35B53`、分隔线 `#303A34`。使用留白、字重和细分隔建立层级。

角色使用本地 PNG，其他图标和图表使用原生绘图。插图等比显示；操作目标至少 48dp，文字使用 sp，长金额适应可用宽度。

## 页面

- **账本**：月度收支、预算、分日流水及待核对入口。
- **日历**：按日期查看实际支出和当日流水。
- **统计**：每日收支走势、分类占比及明确图例。
- **记一笔**：类型、分类、时间、商户、备注和数字键盘。
- **我的**：伙伴选择、战利品等价、预算、分类、数据管理和自动记账设置。

## 伙伴与战利品

可选毛茸侦察员、麦晓雯和猫耳伙伴，切换仅改变外观。素材范围见[伙伴素材](character-art.md)。

战利品等价可关闭。真实支出旁显示 `≈ 物品数量`，收入、退款和转账不折算。每件参考金额可修改，改价不影响账目、统计、预算或 CSV。内置 78 项历史资料及计算方式见[物品参考](loot-reference.md)。

## 交互

底部导航用图标和文字标记当前页面；月份与页面切换使用短淡入并尊重系统动画设置。空账本提供记账入口，不预置虚构交易。

保存失败保留编辑内容。需要人工判断的识别结果进入待核对，日期未确认时不可直接入账。角色与趣味显示不增加记一笔的操作步骤。
