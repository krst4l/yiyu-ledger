# 安卓机型适配

粥粥记账使用 Android 公共接口，最低 Android 8.0（API 26）。适配面向近年主流安卓手机；安装成功、手动记账、后台识别和支付页面识别分别记录结果。当前仅有 [一加 13 的部分实机记录](device-validation.md)，尚无跨品牌验证结论。

## 权限与后台设置

进入“我的 → 自动记账 → 机型与后台设置”，按需要打开通知使用权、无障碍或应用详情。系统入口不可用时，可在手机设置中搜索对应名称。

| 手机 / 系统 | 可查找的后台选项 | 当前验证情况 |
| --- | --- | --- |
| 小米、Redmi / HyperOS、MIUI | 应用自启动、应用省电策略、最近任务锁定 | 待验证 |
| OPPO、一加、realme / ColorOS、OxygenOS、realme UI | 耗电管理、允许后台活动、自启动、最近任务锁定 | 一加 13 有部分记录；其余待验证 |
| vivo、iQOO / OriginOS、Funtouch OS | 后台耗电管理、自启动、后台高耗电、最近任务锁定 | 待验证 |
| 荣耀 / MagicOS | 应用启动管理、允许后台活动 | 待验证 |
| 三星 / One UI | 后台使用限制、不休眠应用 | 待验证 |
| Pixel、摩托罗拉及接近原生 Android 的系统 | 应用电池用量、后台使用、无限制 | 待验证 |
| 华为中兼容 Android APK 的系统 | 应用启动管理、后台活动、电池优化 | 待验证 |

菜单名称随系统版本、地区和机型变化，找不到的项目可跳过。鸿蒙 NEXT 等不兼容 Android APK 的系统不在本应用安装范围内。

通知使用权和无障碍分别授权，并在应用内开启识别、选择来源。清后台、强行停止或系统省电可能中断服务；授权关闭后需手动重新开启，应用不会自动恢复权限。

## 记录适配结果

先用已有付款详情观察页面候选，或等待正常付款时出现通知，无需为验证专门付款。到“待核对”分别检查金额、商户、日期与重复情况；收到事件或服务已连接不代表识别成功。

在“机型与后台设置”手动复制兼容性信息，检查后粘贴到 [机型兼容性反馈表](https://github.com/krst4l/yiyu-ledger/issues/new?template=device-compatibility.yml)。报告只包含机型、系统与应用版本、识别开关、微信和支付宝来源选择、权限及电池优化状态，不会自动上传。不要附账单截图、通知正文、账号、设备序列号或完整日志。

反馈请注明来源应用版本、通知或页面识别、页面状态，以及是否清后台。系统或支付应用更新后的结果需要重新记录；分身和工作资料中的应用也不能用主应用结果替代。
