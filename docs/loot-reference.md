## 默认趣味金额

以 **一只赛伊德的怀表对应 ¥20.00** 为自定基准，有历史均价的物品按下式计算，四舍五入到分：

`默认参考金额 = 物品历史均价 ÷ 212624 × ¥20.00`

例如万足金条默认参考 ¥30.78。显示数量 = 真实支出 ÷ 单件参考金额，带 `≈` 标记。未设置的项目不参与换算；在“我的 → 战利品等价 → 物品对照与参考金额”可逐项修改。

这只是趣味显示参数，不是人民币与哈夫币的汇率。应用使用离线历史资料；调整金额或关闭显示不改变真实账目、统计、预算及 CSV。
