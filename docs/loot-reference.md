# 战利品等价：物品参考快照

一隅记账 v0.4.0 在真实支出旁提供可关闭的“≈ 物品数量”趣味显示。下表用于说明内置名称、历史参考与默认参数，不是游戏当前完整图鉴。

## 来源与范围

- 来源：[游侠网《三角洲行动》红色物品图鉴大全](https://gl.ali213.net/html/2025-12/1726225.html)。
- 来源发布日期：**2025-12-12**；本项目整理日期：**2026-10-28**。
- 实际收录 **78 项**，该页各项配图标题旁均显示红色双菱品质标记；这是第三方图鉴的历史快照，不是官方目录或当前游戏物品总数。
- 其中 **57 项**有文章明确标注的“近期平均价格”，单位为游戏内哈夫币；**21 项**未提供数值，保留未设置状态，不推测价格。
- “赛伊德的怀表”“万足金条”均在该红色清单中；黄金外观不等于金色品级。
- 正文“电子脚镜”按同页对应游戏截图的名称“电子脚镣”校正，其余名称保留该页表述。

## 默认趣味金额

默认把 **一只赛伊德的怀表对应 ¥20.00**，仅作为项目自定的趣味比例。其余有历史数值的物品按下式生成参考金额，四舍五入到人民币分：

`默认参考金额 = 物品历史均价 ÷ 212624 × ¥20.00`

例如万足金条对应默认参考 ¥30.78。物品显示数量为真实支出除以单件参考金额，始终带 `≈` 标记。来源缺少历史数值的 21 项默认未设置，不参与换算；你可以在“我的 → 战利品等价 → 物品对照与参考金额”为每件设置自己的金额。

这套比例不是官方物价、实际购买价格或人民币与哈夫币的汇率。游戏价格会变化，文章配图中的单次价格也可能与文字近期均价不同。应用使用内置静态资料，全离线运行，不实时抓取交易行。调整参考金额或关闭显示，不改变真实账目、SQLite 数据、收支统计、预算及 CSV。
